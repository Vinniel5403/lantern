โปรเจควิชา Physical Computing

LANTERN

โคมไฟอัจฉริยะที่สั่งเปิด-ปิดด้วยเสียง

แตะหลอดเพื่อเปิดไฟ

ไอเดียของเรา

LANTERN คือระบบสั่งงานด้วยเสียงแบบ hands-free เรียก “ตี๋” แล้วพูด “เปิด” หรือ “ปิด” เพื่อควบคุมโหลดแรงดันต่ำ

ปัญหาที่เจอ

ลดการพึ่งพาสวิตช์ในเวลาที่มือไม่ว่างหรือเดินไปกดได้ลำบาก

สิ่งที่เราทำ

Backend ตรวจเสียงและคำสั่ง แล้วส่ง JSON ผ่าน Wi-Fi ให้ ESP32

บทคัดย่อ

บทคัดย่อ

Lantern เป็นต้นแบบระบบสั่งงานอุปกรณ์ด้วยเสียงภาษาไทยแบบ hands-free ใช้ ESP32, INMP441, LCD 16x2 I2C, LED และรีเลย์แรงดันต่ำ โดยใช้ FastAPI และ Typhoon ASR รุ่น typhoon-asr-realtime

ESP32 รับเสียง mono 16 kHz ผ่าน I2S ใช้ VAD แบ่งเสียงเป็นช่วง แล้วส่งไฟล์ WAV แบบ PCM16 ด้วย HTTP POST ไปยัง backend Backend เรียก ASR ตรวจคำปลุก “ตี๋” และอนุญาตคำสั่ง LIGHT_ON หรือ LIGHT_OFF

ระบบแยกส่วนรับเสียง ประมวลผลภาษา และควบคุมอุปกรณ์อย่างชัดเจน พร้อมแสดงสถานะผ่าน LCD และ LED เพื่อรองรับการขยายอุปกรณ์ในอนาคต

การทำงาน

ระบบใช้ INMP441, ESP32, LCD, FastAPI และรีเลย์แรงดันต่ำ สำหรับควบคุม LED หรือโหลด DC เท่านั้น

ESP32 ส่ง WAV ผ่าน Wi-Fi ไปยัง FastAPI ที่ 0.0.0.0:8000 แล้วรับ JSON กลับมา Backend ไม่ได้ควบคุม GPIO โดยตรง

  1. พูด “ตี๋ เปิดไฟ” หรือ “ตี๋ ปิดไฟ”
  2. ไมค์ INMP441 แปลงเสียงเป็นสัญญาณดิจิทัล ส่งเข้า ESP32 ผ่าน I2S
  3. ESP32 อัดเสียงแล้วส่งไป backend ทาง Wi-Fi
  4. Backend ตรวจคำปลุกและคำสั่ง แล้วตอบ JSON
  5. ESP32 สั่งรีเลย์ GPIO23 และแสดงผลผ่าน LED/LCD
  6. รีเลย์ต่อหรือตัดโหลด DC ผ่าน COM และ NO

การต่อวงจร

ต่ออุปกรณ์ตามลำดับ และถอด USB ก่อนย้ายสาย GPIO อ้างอิงจาก lantern_config.h

สรุปขา GPIO ของ ESP32

อุปกรณ์ GPIO หมายเหตุ
INMP441 BCLK (SCK) 26 I2S
INMP441 WS (LRCLK) 25 I2S
INMP441 SD (DOUT) 33 I2S
LCD SDA 18 I2C 0x27
LCD SCL 19 I2C 0x27
Relay IN (S) 23 Active LOW
LED แสดงสถานะ 17 ผ่านตัวต้านทาน

  1. เตรียมราง GND และไฟเลี้ยง

    ต่อ GND ร่วมก่อนจ่ายไฟ อุปกรณ์ทุกตัวใช้รางเดียวกัน

    ขา ESP32ต่อไปที่
    GNDราง − (GND ร่วม)
    3V3ไมค์ INMP441 เท่านั้น
    VIN (5V)รีเลย์ และ LCD (ถ้าใช้ 5V)

  2. ไมค์ INMP441

    ใช้ไฟ 3.3V เท่านั้น ห้ามต่อ 5V

    ขา INMP441ต่อกับ ESP32
    VCC3V3
    GNDGND
    SCK / BCLKGPIO26
    WS / LRCLKGPIO25
    SD / DOUTGPIO33
    L/RGND ผ่าน resistor pull-down (เลือกช่องซ้าย)

    L/R ต่อ GND ผ่าน resistor pull-down เพื่อเลือกช่องซ้าย

  3. จอ LCD 16x2 I2C

    จอแสดงสถานะ ใช้ I2C ที่อยู่ 0x27

    ขา LCDต่อกับ ESP32
    VCCVIN (5V) หรือ 3V3 (ตามสเปกบอร์ด)
    GNDGND
    SDAGPIO18
    SCLGPIO19

    ระวัง: ตรวจ pull-up SDA/SCL ไม่ให้เป็น 5V และ firmware จะสแกน address สำรองให้เมื่อไม่พบ 0x27

  4. โมดูลรีเลย์ 5V

    ขดลวดใช้ 5V ส่วน IN รับสัญญาณจาก ESP32

    ขารีเลย์ต่อไปที่
    VCCVIN (5V) หรือแหล่งจ่าย 5V ภายนอก
    GNDGND (ร่วมกับ ESP32)
    IN (S)GPIO23 Active LOW
    COM / NOต่ออนุกรมกับโหลด DC แรงดันต่ำ

    Active LOW: GPIO23 = LOW ทำงาน, HIGH ปล่อย ตรวจสอบ logic 3.3V ของโมดูลก่อนใช้จริง

  5. LED แสดงสถานะ

    ต้องต่อตัวต้านทานเพื่อป้องกัน LED และ GPIO

    ขา LEDต่อไปที่
    Anode (+) ขายาวตัวต้านทาน 220Ω–1kΩ → GPIO17
    Cathode (−) ขาสั้นGND

  6. จ่ายไฟและทดสอบ

    ตรวจสาย แล้วเสียบ USB 5V เปิด Serial Monitor 115200 baud

    ตรวจผลที่ควรเห็น
    LCDขึ้น LANTERN BOOTING แล้วเป็น READY / SAY TEE
    SerialLCD I2C scan: SDA=18 SCL=19 และ Relay controller ready: GPIO23
    รีเลย์ไม่ทำงานตอนเปิดเครื่อง (สถานะ OFF)

    แหล่งจ่าย 5V แยกต้องต่อ GND ร่วมกับ ESP32

คำเตือนด้านความปลอดภัย

ศึกษาอุปกรณ์และวงจรให้เข้าใจก่อนทำงาน เพราะรีเลย์อาจเกี่ยวข้องกับไฟบ้าน 220V ซึ่งเสี่ยงไฟดูด ไฟไหม้ และอุปกรณ์เสียหาย

โปรเจกต์นี้ทดสอบเฉพาะแรงดันต่ำ ห้ามต่อ 220V กับบอร์ดหรือสายไฟเปลือย งานไฟบ้านต้องใช้อุปกรณ์ป้องกันและช่างไฟฟ้าที่มีความชำนาญ
